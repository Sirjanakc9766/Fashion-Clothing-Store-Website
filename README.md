# Fashion Clothing Store Website
A responsive clothing store website built for the FWDD course assignment. Users can browse fashion items, view product details, and add items to a cart, contact the store, view the location of the stores, filter product like by price high to low, low to high and other. you can see different section of women, men and children.

## Features

- Home page with featured products
- Product listing for [men / women / kids / Online]
- [Shopping cart / wishlist]
- Contact / About page / Information / Our Policies
- Responsive design for mobile, iPad, laptop and desktop 

## Technologies Used

- HTML
- CSS
- JavaScript
